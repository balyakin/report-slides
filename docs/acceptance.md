# Журнал приёмки Report Slides

Дата актуального прогона: **14 октября 2026**. Основание: [TZ-report-slides.md](TZ-report-slides.md).
Статусы: `passed` — проверка выполнена; `failed` — обнаружена неисправность; `pending` — ещё не проверено.

Реализация проверена на macOS. **Внешняя приёмка Microsoft 365 на Windows не завершена**: чтение PPTX
и рендеринг LibreOffice не подтверждают открытие без восстановления и редактирование в PowerPoint.

Транзитивные зависимости не закреплены общим lock-файлом.

AppTest выводит штатное предупреждение `missing ScriptRunContext` для основного потока тестов.
Исключений приложения и отказов тестов нет. Все данные вымышленные.

Команды из каталога проекта:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip check
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8504 --browser.gatherUsageStats false
```

Браузерный сценарий запускается при работающем сервере. Дополнительные средства не нужны самому приложению:

```bash
.venv/bin/python -m pip install playwright==1.63.0
.venv/bin/python -m playwright install chromium
.venv/bin/python tests/browser_smoke.py --output /tmp/report-slides-browser
```

Для установленного Chrome можно передать путь к исполняемому файлу через `REPORT_SLIDES_BROWSER`.
Без `--output` снимки сохраняются во временный каталог; файлы репозитория не перезаписываются.
[Загрузка и данные](assets/browser-upload.png), [готовый отчёт](assets/browser-report.png),
[ошибка CSV](assets/browser-error.png) пересняты в актуальном прогоне.

## Продолжение приёмки в Microsoft 365 на Windows

Все пункты ниже **pending**. Записать версии Windows, браузера, Excel и PowerPoint, дату и фактический результат.

1. Выполнить команды Windows из README с чистого окружения. Загрузить образец и получить 5 слайдов.
2. Открыть PPTX без восстановления. Изменить текст титула, ячейку таблицы и данные диаграммы через «Изменить данные».
3. Сохранить файл, закрыть и открыть повторно. Проверить сохранение всех трёх правок и добавить слайд из макета 16:9.
4. Создать пять файлов через `tests/make_previews.py`; проверить каждый слайд, длинный текст, крайние числа и нули.
5. Пройти новый CSV, отказ загрузчика, неверные числа, смену разделителя и полей; старый PPTX не должен предлагаться.
6. Пройти весь сценарий только клавиатурой и с экранным диктором. Проверить фокус и объявления ошибок.
7. Экспортировать обезличенную книгу Excel в CSV UTF-8, выбрать фактический разделитель и сверить значения.

Проблемы макета исправлять без сокращения текста, допустимых лимитов и размера шрифта.

## История проверок и пилот

Прогоны 13 октября на Linux/Python 3.12.3 дали сначала 39, затем 43 теста. Это исторические результаты;
текущий набор содержит 58 тестов. Старые снимки заменены результатами проверки macOS от 14 октября.

Реальный обезличенный отчёт, пилот с пятью участниками и сравнение с PPT Master/Presenton остаются **pending**.
Причина — отсутствие реальных исходных данных и участников. Сценарий — в [eval/pilot.md](../eval/pilot.md).
Готовность к внешней приёмке не означает доказанного преимущества перед конкурентами.
